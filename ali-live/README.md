# Ali Live - 阿里云直播服务

阿里云视频直播服务集成。

## 平台介绍

阿里云视频直播提供：

- **推流服务**：RTMP/SRT 推流
- **播放服务**：RTMP/FLV/HLS/RTS 播放
- **转码服务**：实时转码
- **录制服务**：直播录制
- **截图服务**：实时截图
- **鉴黄服务**：内容审核

## 功能规划

- [ ] 创建/关闭直播
- [ ] 生成推拉流地址（带鉴权）
- [ ] 流状态监控
- [ ] 直播录制
- [ ] 直播转码
