# Agora Live - 声网直播服务

声网 (Agora) 实时音视频直播服务集成。

## 平台介绍

声网（Agora）是全球领先的实时互动云服务商，提供：

- **RTC 实时音视频**：超低延迟（< 400ms）
- **互动直播**：支持连麦、PK
- **云录制**：服务端录制
- **实时消息**：RTM 信令服务
