# ZEGO Live - 即构直播服务

即构 (ZEGO) 实时音视频直播服务集成。

## 平台介绍

即构科技（ZEGO）提供：

- **实时音视频**：低延迟通话
- **互动直播**：高并发直播
- **即时通讯**：IM 消息服务
- **实时语音**：语音通话
- **云端录制**：服务端录制
